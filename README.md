# Best Price

It is a shopping app that helps users find the best deals by comparing prices for the same product in different volumes or quantities. Whether you're buying a single item, a bulk pack, or a larger size, the app quickly shows you where you can get the best price per unit.

# 🛠 Getting Started

## ⚙️ Prerequisites

| Tool             | Version |
| ---------------- | ------- |
| Node.js          | >= 22   |
| React Native CLI | Latest  |
| Android Studio   | Latest  |
| JDK              | 17      |

---

### Installation

```bash
git clone https://github.com/night-fury-rider/star-vault-app.git
cd star-vault
npm install
```

### Run

```bash
npm run android
```

## Scripts

```bash
# Enter in Sandbox mode
npm run mode:sandbox
```

```bash
# Exit the Sandbox mode
npm run mode:prod
```

```bash
# Export source files
npm run export-src
```
